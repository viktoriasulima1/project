# Sprint 21 Feature Freeze

Sprint 21 is limited to evidence-backed offline safety and pilot hardening. Allowed changes are data-loss, duplicate-sync, user/farm isolation, session recovery, service-worker update, queue/conflict UX, mobile/PWA lifecycle and recurring real-device P2 fixes.

Voice, GPS detection, satellite imagery, background geolocation, native apps, telemetry, Finance work and unrelated modules are frozen. A proposed change outside the allowed list is deferred unless it directly resolves a documented P0/P1 from the physical-device record.

Every accepted defect must include device/browser evidence, severity, fix, automated regression where reproducible, and physical retest result.
