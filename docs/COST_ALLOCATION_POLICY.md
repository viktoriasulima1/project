# Cost Allocation Policy

Supported methods are direct field, per hectare, per crop area, equal active field, yield proportional, and unallocated.

Direct entries must name a farm-owned FieldSeason. Shared entries remain visibly unallocated until an explicit method and eligible set are recorded. Amount allocation uses deterministic weights and assigns rounding remainder to the final allocation so the allocated total equals the source total.

Operational input usage is already direct activity cost and must not be re-entered as a manual expense. Purchases are inventory acquisition, not field expense. Fuel is either included in a machine hourly rate or tracked separately; both cannot be counted for the same usage. Gross margin shows direct cost, allocated overhead and unallocated values separately.

No allocation is inferred from a field name, crop name, buyer, invoice or proximity.
